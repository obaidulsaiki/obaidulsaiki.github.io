# Modern Portfolio & Research Website (`Obaidul Haque`)

## What This Is

A modern, highly polished multi-page personal portfolio and research website for Obaidul Haque, AI Engineer & Researcher specializing in Computer Vision (CV), Natural Language Processing (NLP), and Signal Processing. Built with Next.js, Framer Motion, and Tailwind CSS using an artisanal 4-color palette (#FFFBF1, #FFF2D0, #FFB2B2, #E36A6A), hosted statically on GitHub Pages (`obaidulhaque.me` / `obaidulsaiki.github.io`).

## Core Value

Deliver an unforgettable, lightning-fast personal showcase across 7 dedicated sections that highlights AI research in CV/NLP/Signal Processing, enterprise engineering roots in Java & Spring Boot, and modern web architectures with seamless micro-animations.
